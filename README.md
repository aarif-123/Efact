# EFACT Robotics website

This is a static HTML, CSS, and asset site. Vercel can deploy it without a build step.

## Deploy with Vercel

Import `aarif-123/Efact` in Vercel and use the repository root as the project root. Select the **Other** framework preset, leave the build command empty, and set the output directory to `.`. The included `vercel.json` enables clean URLs.

The site entry point is `index.html`; local images, styles, and the favicon are under `assets/` and `styles.css`.
